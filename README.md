# Tianyi Yu — personal research website

https://terry0809000.github.io/

A curated portfolio of 12 research projects across six directions. The explicit selection is recorded in `portfolio-selection.json`; unlisted projects are absent from the site HTML and search results.

Home, About, Research, Projects and Connect have independent HTML pages with shared top navigation. Each research direction has its own project page. The full project list uses six-card pagination and search; all selected projects remain available without JavaScript.

GitHub Pages serves `main` from the repository root. The site keeps its own hero artwork and links each project directly to its selected public repository, so it does not depend on the visibility of a separate profile or portfolio repository.
